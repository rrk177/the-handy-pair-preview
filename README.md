# The Handy Pair — landing page concepts

Two design directions for a family-run cleaning company.
Open `index.html` and use the top toggle to switch between:

- **V1 — Editorial** (Bricolage grotesk, bone & brown)
- **V2 — Corporate Calm** (Newsreader serif, airy)

Image slots are flat CSS stand-ins; real photography drops in later.
